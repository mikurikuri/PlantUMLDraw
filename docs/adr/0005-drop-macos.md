# ADR-0005: macOS をサポート対象外とする

- 状態: 承認
- 日付: 2026-11-15
- 関連: [ADR-0001](0001-technology-stack.md) の「Windows / macOS / Linux で動くこと」という前提を変更する

## 背景

当初は Windows / macOS / Linux の 3 OS を対象にしていた。主な利用者（社内）の環境は Windows で、macOS 版を使う予定がない。
macOS 対応を続けると、CI の実行時間やコスト、署名・公証の手間、OS ごとの差の調査が増える。

## 決定

- 対応 OS は **Windows と Linux** とする。**macOS は対象外**とする。
- CI のマトリクスから macOS を外す。
- macOS 向けのインストーラー（dmg）、署名・公証、アイコン（`.icns`）は作らない。
- macOS でしか起きない不具合の報告は受け付けない。README にその旨を書く。

## 検討した代替案

| 案                             | 評価                                                           |
| ------------------------------ | -------------------------------------------------------------- |
| 3 OS 対応を続ける              | 利用予定がないのに CI 時間と保守の手間が増える                 |
| macOS をベストエフォートで残す | 「動くかもしれない」状態は期待と問い合わせを生むため明確に外す |

## 影響

- Tauri はクロスプラットフォームのため、コード上で macOS を意図的に壊すことはしない。macOS 向けに特別なコードも書かない。
- 将来 macOS が必要になったら、新しい ADR で見直す。
