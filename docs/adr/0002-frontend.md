# ADR-0002: フロントエンドに React + TypeScript + Vite、エディター部品に CodeMirror 6 を採用する

- 状態: 承認
- 日付: 2026-11-15

## 背景

エディター・プレビュー・設定画面などの UI を作る。利用者が多く情報が見つけやすいこと、テストしやすいことを重視する。

## 決定

- UI フレームワーク：**React 18 + TypeScript**
- ビルドツール：**Vite**
- 単体テスト：**Vitest + Testing Library**
- テキストエディター部品：**CodeMirror 6**（イテレーション 1 で導入）

## 検討した代替案

| 案            | 評価                                                                                             |
| ------------- | ------------------------------------------------------------------------------------------------ |
| Svelte / Vue  | 軽量で書きやすいが、社内での知見は React の方が多い                                              |
| Monaco Editor | 高機能だがサイズが大きく、独自言語の定義（ハイライト・補完）は CodeMirror 6 の方が組み込みやすい |

## 影響

- 社内試作が別のフレームワークだった場合、イテレーション 1 開始前までに本 ADR を見直す。
