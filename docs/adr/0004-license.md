# ADR-0004: アプリは MIT ライセンスで公開し、PlantUML は MIT 版を利用する

- 状態: 承認
- 日付: 2026-11-15

## 背景

GitHub で公開し、会社でも自由に使えるようにしたい。また PlantUML 本体の扱い（同梱するか）を決める必要がある。

## 決定

- 本アプリのライセンスは **MIT** とする。
- PlantUML 本体は、複数あるライセンス版のうち **MIT 版（plantuml-mit）** を利用する。同梱する場合もこの版に限る。
- 同梱するサードパーティ製品のライセンス表記は `THIRD_PARTY_NOTICES.md` にまとめる（配布物を作るイテレーション 5 までに作成）。

## 検討した代替案

| 案                     | 評価                                                                        |
| ---------------------- | --------------------------------------------------------------------------- |
| Apache-2.0             | 特許条項があり企業向けには堅いが、条文が長く、社内での説明は MIT の方が簡単 |
| GPL 版 PlantUML を同梱 | 配布物全体に GPL の条件が及ぶおそれがあるため不採用                         |

## 影響

- MIT 版 PlantUML は一部機能（例：PDF 出力の一部ライブラリ依存）が含まれない場合がある。必要になった時点で再検討する。
- 公開前に、会社の OSS 公開ポリシーを確認する（開発計画 D6）。
