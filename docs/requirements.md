## 2. ユースケース詳細

### UC-01：`.puml` を開いて編集し、図を確認して保存する

- **利用者**：設計者
- **正常系**
  1. ツールバーまたは Ctrl+O でファイルを開く
  2. 左のエディターで編集すると、右のプレビューが自動で更新される
  3. Ctrl+S で保存する
- **確認できたら合格**：開く → 編集 → 図の更新 → 保存が一通りでき、保存したファイルが他のエディターでも開ける
- **メモ**：イテレーション 1 の受け入れ基準 AC1-1〜AC1-7 で詳細に確認する
