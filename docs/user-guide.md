# ユーザーガイド

## 必要なもの

- Windows 10 / 11、または Linux
- **Java 17 以降**（例：`winget install EclipseAdoptium.Temurin.21.JDK`）

PlantUML 本体（plantuml.jar）はアプリに同梱されています。

## 画面

| 場所 | 内容                                                                  |
| ---- | --------------------------------------------------------------------- |
| 上部 | ツールバー（新規・開く・保存・名前を付けて保存・設定）とファイル名    |
| 左   | エディター                                                            |
| 右   | プレビュー。入力が止まると自動で更新されます                          |
| 下部 | 文字コード（UTF-8 / BOM の有無）、改行コード（LF / CRLF）、描画の状態 |

左右の境界はドラッグで幅を変えられます（境界を選択して ← → キーでも調整できます）。

## 操作

| 操作             | ショートカット |
| ---------------- | -------------- |
| 新規             | Ctrl+N         |
| 開く             | Ctrl+O         |
| 保存             | Ctrl+S         |
| 名前を付けて保存 | Ctrl+Shift+S   |

- ファイル名を指定してアプリを起動すると、そのファイルを開きます（エクスプローラーの「プログラムから開く」でも使えます）。
- 保存するときは、開いたときの文字コード（BOM の有無）と改行コードをそのまま保ちます。
- 拡張子なしで保存すると `.puml` が付きます。
- 未保存の変更があるときは、ファイル名の横に ● が付きます。この状態で閉じる・開く・新規にすると確認が出ます。

## エラーが出たとき

| 表示                                       | 対処                                                                                           |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| 「N 行目：Syntax Error?」など              | 図の記述に誤りがあります。該当行を確認してください。直前に描けた図は薄く表示されたまま残ります |
| 「Java が見つかりません」                  | Java をインストールしてアプリを起動し直すか、「設定」で java のパスを指定してください          |
| 「plantuml.jar が見つかりません」          | アプリを入れ直すか、「設定」で plantuml.jar のパスを指定してください                           |
| 「UTF-8 のファイルではないため開けません」 | Shift_JIS などのファイルです。別のエディターで UTF-8 に変換してから開いてください              |

## 設定

「設定」ボタンで次を指定できます。空欄の場合は自動で探します。

- **java のパス**：空欄なら `JAVA_HOME` → PATH の順に探します。
- **plantuml.jar のパス**：空欄ならアプリ同梱版を使います（環境変数 `PLANTUML_JAR` があればそちらを優先）。

## 現在の制限

- 1 つのファイルに複数の図（`@startuml` が複数）がある場合、先頭の図だけを表示します。
- シンタックスハイライト・補完・ズーム・書き出しは今後の作り込みで検討します（[要件・ユースケース](requirements.md)）。
